# 03. Контент: форматы, визуал, производство

Ключи приводят человека к пину. Дальше решает картинка: сохранит он его или
пролистает. Save rate — это метрика креатива, а не SEO.

## Технические требования

| Параметр | Значение | Почему |
|---|---|---|
| Соотношение сторон | **2:3** | Стандарт ленты. Всё, что длиннее, обрезается |
| Размер | 1000×1500 px | Достаточно для ретины, не раздувает вес |
| Формат | PNG или JPG | PNG — где есть плашки и текст |
| Вес | до 20 МБ (видео до 2 ГБ) | Практический ориентир — до 2 МБ |
| Видео | 4 сек – 15 мин, 9:16 или 1:1 | Видео тянет охват сильнее статики |

Квадрат 1:1 допустим для видео, вертикаль 9:16 — тоже. Горизонтальные картинки
на Pinterest не работают: в вертикальной ленте они занимают втрое меньше места.

## Анатомия работающего пина

```
┌─────────────────────┐
│  ТЕКСТ-КРЮЧОК       │  ← 3–6 слов, 60–80 px, читается в превью
│  (верхняя треть)    │
├─────────────────────┤
│                     │
│   Основной визуал   │  ← конкретика, а не абстракция
│                     │
├─────────────────────┤
│  уточнение · бренд  │  ← мелкий текст, логотип/домен
└─────────────────────┘
```

Что действительно влияет:

- **Текст на изображении обязателен.** Пин без текста проигрывает пину
  с текстом почти всегда: человек листает ленту и решает за полсекунды.
- **Контраст.** Тёмный текст на светлой плашке или наоборот. Текст поверх
  пёстрого фото не читается на телефоне.
- **Одна мысль на пин.** Не «10 советов», а один конкретный.
- **Лица и руки работают** в темах «сделай сам», еда, лайфстайл.
- **Домен внизу** — узнаваемость и защита от кражи атрибуции.

## Форматы, которые стоит чередовать

| Формат | Когда | Что даёт |
|---|---|---|
| Список-гайд («7 бухт без толпы») | Основа ротации | Высокий save rate |
| Сравнение «до/после», «А vs Б» | Раз в неделю | Останавливает пролистывание |
| Инфографика/чек-лист | 1–2 в неделю | Максимум сохранений |
| Видео 15–30 сек | 2–3 в неделю | Больше показов |
| Многостраничный пин | Раз в неделю | Глубина, время просмотра |
| Одиночное фото + подпись | Редко | Слабый формат, только как разбавление |

## Производство: как не выгореть на второй неделе

Ошибка новичка — делать пин с нуля каждый раз. Правильно — **шаблон + конвейер**:

1. **Один раз** сделать 3–5 шаблонов 1000×1500 (заголовок, плашка, место под
   фото, подпись с доменом).
2. Раз в неделю **пакетом** собирать 30–40 обложек: только замена фото и текста.
   Полтора часа на неделю публикаций.
3. Тексты не писать руками — их генерирует `pk plan` из шаблонов и ключей.
4. Складывать готовые файлы в `assets/pins/`, имена файлов = `id` из
   `ideas.json`.

### Один материал → 5 пинов

Статья «Тихие пляжи Кипра» превращается в пять **разных** пинов:

| # | Угол | Заголовок на картинке | Кластер |
|---|---|---|---|
| 1 | Список | 7 бухт без толпы | beaches |
| 2 | Проблема | Нисси забит? Есть варианты | beaches |
| 3 | Сезон | Куда ехать в октябре | seasons |
| 4 | Аудитория | Пляжи, где не страшно с малышом | beaches |
| 5 | Логистика | Бухты, куда доедешь без джипа | routes |

Разные обложки, разные хвосты, разные недели публикации, одна ссылка. Это
и есть «свежие пины» без дублирования (см. [00-strategy.md](00-strategy.md)).

## Ритм публикаций

Задаётся один раз в `cadence` конфига:

```json
"cadence": {
  "pins_per_day": 6,
  "slots": ["08:30", "11:00", "13:30", "16:00", "19:00", "21:30"],
  "days": ["mon", "tue", "wed", "thu", "fri", "sat", "sun"],
  "max_per_board_per_day": 2,
  "min_gap_minutes": 90
}
```

- **`slots`** — часы в таймзоне вашей аудитории, не вашей. Вечер и выходные
  на Pinterest традиционно активнее.
- **`max_per_board_per_day`** — не заваливать одну доску: 2 пина в день на
  доску достаточно.
- **`min_gap_minutes`** — паузы между публикациями. Пачка из шести пинов
  в одну минуту выглядит как бот.

Планировщик разложит идеи сам и не даст нарушить эти правила:

```bash
pk plan -i ideas.json --start 2026-08-05 --days 30
pk calendar --days 7     # посмотреть, что и когда выходит
```

Пин уходит на доску, которая ведёт его кластер (`boards[].clusters`), — еда
не попадёт в «Маршруты».

## Сезонность

Pinterest — площадка планирования: люди ищут заранее. Публикуйте **за 30–45
дней** до события (факт, официальная рекомендация Pinterest).

| Тема | Когда публиковать |
|---|---|
| Лето, отпуск | Март–апрель |
| Школа, «снова в строй» | Июль |
| Новый год | Начало ноября |
| Летние маршруты | Апрель–май |

Сезонный кластер (`seasons` в примере конфига) держите живым круглый год —
это стабильный источник показов в межсезонье.

## Что делать с уже опубликованным

- **Не удалять** слабые пины: они не мешают, а иногда «просыпаются» через
  месяцы.
- **Не менять картинку** у опубликованного пина — заведите новый.
- **Заголовок и описание** править можно и нужно, если пин собирает показы,
  но не сохранения.
- **Повторять успех**: пин с высоким save rate — это подтверждённый спрос.
  Сделайте 3 новых пина на ту же тему под другими углами.
