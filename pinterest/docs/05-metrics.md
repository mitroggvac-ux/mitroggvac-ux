# 05. Метрики: что считать и какие решения из этого следуют

Метрика без порога и без решения — украшение отчёта. Здесь для каждой метрики
записано, что делать при плохом значении. Эти же пороги зашиты в `report.py`,
поэтому `pk report` выдаёт не таблицу, а список действий.

## Метрики по приоритету

### 1. Save rate — главная

```
save rate = сохранения / показы × 100%
```

Отвечает на вопрос «контент вообще нужен людям?». Сохранение — это сигнал,
по которому Pinterest решает, показывать ли пин дальше.

| Значение | Диагноз | Действие |
|---|---|---|
| < 0.3% | Креатив не работает | Пересобрать шаблоны обложек, сменить формат |
| 0.3–0.5% | Ниже нормы | 3 варианта обложки на один ключ, сравнить |
| 0.5–1.5% | Норма | Наращивать объём |
| > 1.5% | Отлично | Масштабировать формат и тему |

**Порог в тулките: 0.5%** (`report.SAVE_RATE_FLOOR`).

### 2. Показы (impressions) и их динамика

Абсолютное число почти бесполезно, важна динамика. Отчёт делит окно пополам
и сравнивает половины.

| Прирост между половинами | Диагноз | Действие |
|---|---|---|
| < 5% | Рост встал | Сначала проверить регулярность, потом семантику |
| 5–30% | Здоровый рост | Ничего не менять |
| > 30% | Разгон | Найти причину и повторить её |

**Порог в тулките: 5%** (`report.STALLED_GROWTH`).

Провал показов при неизменной работе — сначала проверьте, не было ли пропусков
в публикациях 2–3 недели назад: эффект приходит с задержкой.

### 3. Outbound clicks — если есть сайт

```
click rate = исходящие клики / показы × 100%
```

| Значение | Диагноз | Действие |
|---|---|---|
| < 0.2% | Пин закрывает тему целиком | Оставлять открытый вопрос, явный повод перейти |
| 0.2–0.5% | Норма | — |
| > 0.5% | Сильно | Проверить, что посадочная не сливает трафик |

**Порог в тулките: 0.2%** (`report.CLICK_RATE_FLOOR`).

Высокие сохранения при нулевых кликах — нормальная ситуация для медиа-роста,
но если цель — трафик, это первый кандидат на починку.

### 4. Показов на пин

```
показов на пин = показы кластера / число пинов кластера
```

Честнее общих показов: показывает эффективность единицы контента, а не
последствия объёма. Растёт — вы делаете лучший контент. Падает при растущих
общих показах — вы просто заливаете больше, качество падает.

### 5. Подписчики — метрика последнего приоритета

Растут как следствие. Не оптимизируйте под них и не сравнивайте себя по ним
с чужими аккаунтами: 500 подписчиков при 300k показов — нормальная и здоровая
картина для Pinterest.

## Что игнорировать

- **Ежедневные колебания.** Данные Pinterest обновляются с задержкой (обычно
  24–48 часов) и скачут. Смотреть неделя к неделе.
- **Первые 3–6 недель.** Показов почти не будет. Это не сигнал.
- **Один вирусный пин.** Он искажает всю сводку. Смотрите на медиану кластера.
- **Чужие скриншоты.** Ниши несравнимы.

## Как снимать

```bash
pk pull --days 30 --pins 50      # снапшот в data/analytics/
pk report -o data/report.md      # отчёт с рекомендациями
```

Снапшоты накапливаются в `data/analytics/` — это ваша история, отчёт всегда
строится по последнему.

Что делает `pk report`:

- сводка по метрикам за окно + сравнение половин окна;
- цели из `goals` против факта;
- разбивка по кластерам с save rate и показами на пин;
- список конкретных действий по порогам выше;
- предупреждение, если в очереди меньше недели контента;
- список пинов, по которым аналитика не собралась.

## Цели в конфиге

```json
"goals": {
  "monthly_impressions": 300000,
  "monthly_saves": 3000,
  "monthly_outbound_clicks": 1500,
  "audience": 20000
}
```

Ставьте цели от своей прошлой динамики, а не от чужих цифр. Разумный шаг для
растущего аккаунта — **+30–50% к предыдущему месяцу**. Цель, которая
недостижима в принципе, ломает всю обратную связь: отчёт будет вечно красным,
и вы перестанете его читать.

## Ритм анализа

| Частота | Что смотрим | Какие решения |
|---|---|---|
| Ежедневно | `pk status --state failed` | Технические сбои публикации |
| Еженедельно | Показы и сохранения к прошлой неделе | Корректировка тем недели |
| Ежемесячно | `pk report` целиком | `weight` досок, семантика, форматы |
| Раз в квартал | Динамика 90 дней | Расширение или сужение ниши |
